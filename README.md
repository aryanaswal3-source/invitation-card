# 🎂 Dhruvi's 1st Birthday Invitation 🎉

> **Something special is waiting for you... ❤️**

A beautiful and interactive **digital birthday invitation card** created for **Kartik Negi (Dhruvi)** on the occasion of his **1st Birthday**.

Instead of sending a traditional invitation, this project turns the birthday invitation into a small interactive web experience that can easily be shared with family and friends through a link.

---

## ✨ Features

- 🎂 Personalized 1st Birthday Invitation
- 👶 Birthday boy: **Kartik Negi (Dhruvi)**
- 🎈 Interactive birthday-themed design
- ✨ Smooth animations and visual effects
- 📱 Mobile-friendly responsive design
- 💻 Works on desktop and mobile browsers
- 🔗 Easy to share through a single link
- ❤️ Personalized birthday message

## 💡 Project Idea

The idea behind this project was simple:

Instead of sending a normal birthday invitation image, create a **small interactive website** that feels more personal and memorable.

The invitation can be shared with just one link, allowing guests to open it directly on their phones.
